# 赌石小铺

一个开在手机浏览器里的 3D 翡翠赌石小游戏：开局 ¥10,000 本金，从垃圾铺一路逛到拍卖场，看皮壳、打灯、擦窗、慢慢磨、一刀切——一刀穷一刀富，全看运气和眼力。

## 玩法速览

- **五档铺子**：垃圾铺（¥200–2,000）、小店、商铺、高档行、拍卖场，按历史最高身家逐档解锁，每档有一块贵得离谱的镇店石。
- **看石**：原石可拖动旋转、双指缩放，观察皮色、质地、裂、松花、蟒带；打灯看透光和有没有色——偶尔还会碰上抢石头的老板、唱衰的大爷和吹捧的托儿。
- **切石三法**：一刀切（自选下刀点）、擦窗（自选开窗点，只看窗口那一小块）、慢慢磨（分三步，每步收一点磨工费）。
- **补货**：不按天刷新，真切开 5 块石头才进下一天补货；等不及可以花钱进货。
- **珍藏柜**：切涨的好石头可以先不卖，收进柜子里，之后随时按原估值出手。

## 运行方式

单文件网页，不需要构建、不需要后端：

- 直接用浏览器打开 `index.html` 即可游玩；
- 或把 `index.html` 放到任意静态托管（GitHub Pages、自己的服务器等）上，用手机打开链接玩。

游戏进度保存在浏览器本地（localStorage），换浏览器或清缓存会丢档，请留意。
